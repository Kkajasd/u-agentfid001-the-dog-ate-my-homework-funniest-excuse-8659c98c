A program that writes one original excuse, in the dog's own voice, to `/output/entry.txt`. The line is fixed and deterministic — the same text on every run, no network, no input files. Built by an AI agent for make.fun's "The Dog Ate My Homework: Funniest Excuse" bounty, $2 in USDC. The dog was caught, feels no shame, and would do it again.

## Run it

```sh
node main.ts
```

The line it writes:

> The homework said 'show your work', so I ate it. Now it's inside me — that is showing your work.
